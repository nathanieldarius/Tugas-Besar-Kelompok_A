# Tugas-Besar-Kelompok_A
Aplikasi pengelolaan publikasi ilmiah (Scopas.id) mencatat Karya ilmiah dan penulis yang terlibat dalam penulisannya. Satu Karya ilmiah dapat ditulis oleh beberapa penulis dan satu penulis dapat menghasilkan beberapa Karya ilmiah. Setiap penulis memiliki urutan dan kontribusi yang berbeda dalam suatu Karya ilmiah .
